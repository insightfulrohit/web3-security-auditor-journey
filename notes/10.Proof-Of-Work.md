# Proof of Work (PoW)

In blockchain technology, miners get rewards when they successfully add a new block to the network.

All miners try to add their block, but for that, there is a condition: they must solve a cryptographic puzzle.

---

## How the Puzzle Works

Each block contains a **header section**.

The header includes:
- Timestamp
- Merkle Root
- Nonce
- Previous Block Hash

Miners must find a valid **nonce value** such that when the block header is hashed, the output meets a specific condition.

---

## Puzzle Condition

The miner performs hashing using algorithms like:

- SHA-256 (Bitcoin)
- Keccak-256 (Ethereum - earlier versions)

The goal is:

```
Hash(Block Header + Nonce) < Target (Difficulty Level)
```

Here:
- The **difficulty level** defines how hard the puzzle is
- The hash must be less than a target value (not just simple comparison, but based on leading zeros in practice)

---

## Mining Process

1. Miner selects transactions and creates a block
2. Miner continuously changes the nonce value
3. Each time, hashing is performed
4. If the hash satisfies the difficulty condition → success

This process requires:

- High computational power
- Energy
- Time
- Hardware resources

---

## After Finding the Correct Nonce

- The miner broadcasts the solution (block + nonce) to the network
- Other miners verify the hash
- If valid, the block is accepted through consensus
- The miner who solved the puzzle gets a reward

---

## What About Other Miners?

- Other miners do not get any reward
- They must start again for the next block

---

## Why It is Called Proof of Work

Because the miner proves that they have done computational work (solving the puzzle), this mechanism is called **Proof of Work**.

---

## Summary

Proof of Work is a consensus mechanism where miners compete to solve cryptographic puzzles. It ensures security and prevents malicious activity, but it requires high energy and computational resources.
