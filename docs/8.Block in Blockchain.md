# Block in Blockchain

A blockchain is a distributed ledger and this ledger is made up of multiple blocks.

A ledger has three main properties:

1. The Property of Being Distributed
2. The Property of Being Public
3. The Property of Being Immutable

---

## What is a Block?

A block is a data structure in which transactions and blockchain-related information are stored.

When a block becomes full, the process of adding a new block to the blockchain begins.

This process is usually performed by miners or validators using consensus mechanisms such as:

- Proof of Work (PoW)
- Proof of Stake (PoS)

---

## Genesis Block

The Genesis Block is the very first block of a blockchain.

Since there is no previous block before it, the Genesis Block does not contain any previous block hash. It acts as the starting point of the entire blockchain network. The Genesis Block is predefined by the creators of the blockchain protocol and contains the initial configuration required to start the network. Every other block that is added later can trace its history back to this first block. Because all blocks are connected directly or indirectly to the Genesis Block, it serves as the foundation of the entire blockchain.

---

## Hash Linking

Every block contains the hash of the previous block.

This creates a chain of connected blocks and helps maintain immutability.

Example:

```text
Hash1 = Hash(Block1 Data)

Hash2 = Hash(Block2 Data + Hash1)

Hash3 = Hash(Block3 Data + Hash2)

Hash4 = Hash(Block4 Data + Hash3)
```

In this process:

- Block 2 depends on Hash1
- Block 3 depends on Hash2
- Block 4 depends on Hash3

If someone changes the data inside Block 1:

- Hash1 will change
- Hash2 will change
- Hash3 will change
- Hash4 will change

As a result, the entire chain becomes invalid.

This is one of the main reasons why blockchain is considered immutable and tamper-resistant.

---

## Information Stored Inside a Block

1. Transactions
2. Block Hash
3. Previous Block Hash
4. Version
5. Nonce
6. Merkle Root
7. Difficulty Level

---

## Summary

A blockchain is a distributed ledger made up of multiple blocks. Each block stores transactions and important blockchain information. Every block is connected to the previous block through cryptographic hashes, creating a secure chain. This hash-linking mechanism helps maintain the immutability and integrity of the blockchain.
