# Transaction in Blockchain

## Step 1: User Creates & Signs a Transaction

Example:

Rinki wants to send **1 ETH** to Rohit.

Suppose:

- Amount = 1 ETH
- Gas Fee = 0.299 ETH

```text
1 ETH + 0.299 ETH = 1.299 ETH
```

The transaction is digitally signed using Rinki's private key.

---

## Step 2: Transaction is Broadcast to the Network

The signed transaction is sent to Ethereum network nodes.

All connected nodes receive the transaction information.

---

## Step 3: Nodes Validate the Transaction

Nodes check the transaction.

They verify:

1. Is the signature valid?
2. Does the sender have enough balance?
3. Does the transaction follow network rules?

### Important Point

Every node has the same software.

Examples:

- Bitcoin Node → Bitcoin Software
- Ethereum Node → Ethereum Software

These software programs already contain predefined rules and code.

When a transaction arrives, the node automatically checks and validates it.

---

## Step 4: Transaction Enters the Mempool

After successful validation, the transaction enters the mempool.

Now:

```text
1.299 ETH transaction waits in the mempool
```

until a miner or validator selects it.

---

## Step 5: Miners / Validators Select the Transaction

Miners or validators choose transactions from the mempool.

Usually:

➡️ Transactions with higher fees are selected first.

---  

## Step 6: Block is Created and Validated

Selected transactions are packed into a new block.

The block is then verified by the network.

### What does "Verification" mean?

The block is broadcast to network nodes.

Nodes check:

- Block validity
- Transaction validity
- Network rules

After successful verification:

➡️ The block becomes ready to be added to the blockchain.

---

## Step 7: Block is Added to the Blockchain

The network accepts the verified block.

After that:

- Blockchain is updated
- Ledger is updated

---

## Step 8: Transaction Gets Confirmed

The transaction is now officially recorded on the blockchain.

This means:

✅ Transaction is completed

✅ Permanently stored on the blockchain

✅ Ledger has been updated

---

# 🔄 Complete Flow

```text
User Creates & Signs Transaction
              ↓
Transaction Broadcast to Network
              ↓
Nodes Validate Transaction
              ↓
Transaction Enters Mempool
              ↓
Miners / Validators Select Transaction
              ↓
Block Creation & Validation
              ↓
Block Added to Blockchain
              ↓
Transaction Confirmed
```

---

## Summary

A blockchain transaction starts when a user creates and signs a transaction. The transaction is broadcast to the network, validated by nodes, placed in the mempool, selected by miners or validators, added to a block, verified by the network, and finally recorded permanently on the blockchain.
