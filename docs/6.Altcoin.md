# 🪙 Altcoin & Tokens in Blockchain

## 🔹 Cryptocurrency

Crypto-currency is a type of Digital Currency in which transactions are verified and a decentralized system maintains all the transactions, such currency is called cryptocurrency.

---

## 🔹 Forking

When a new update comes in a blockchain series and all blocks accept it, but some blocks do not accept it, then a fork (separate chain) is created.

## 🔹 Fork Type

Soft Fork: Those which accept the updates.

Hard Fork: Those which do not accept the updates, if these blocks survive for a long time then a new coin is created, such coins are called Altcoins.

Temporary Fork: This is a type of fork which is created in the network for a temporary time. --> How?

This technology is decentralized, many miners in the world are solving the same difficulty problem, so it is possible that Miner A and Miner B both at the same time, with just a few milliseconds difference, broadcast their solution to the network, then in the network both solutions are seen by different miners at different times, so some miners start working on A and some miners start working on B, so here a temporary fork is created, but later it automatically gets solved and comes back to 1 single chain.  **HOW??**



### 🔹 Explanation (Fork Scenario)

Suppose more miners are working on chain A  
and they solve the new difficulty level and add a new block  

➡️ Then chain B (fork) will automatically be discarded  

Now the question:

➡️ What happens to the miners working on chain B?

- Their energy is wasted  
- Their time is wasted  
- Their resources are wasted  

➡️ They do not get any reward ---> Why?

Because blockchain rules say:

1) Always follow the chain with the most cumulative work  
2) No guarantee of reward until enough confirmation  

---

## 🔹 Orphan Block

Discarded blocks are called orphan blocks  

### Properties:

1) They do not become part of the blockchain  
2) Mining reward is canceled  
3) Transactions go back to the mempool

## 🔹 Mempool

- It is a memory pool  
- Transactions stay here and wait  

## 🔹 After Fork Resolution

4) Miners start working on the winning chain  

### Process:

1) Rollback local blockchain state  
2) Download latest block  
3) Resume mining  

### 🔹 Example (Transaction Flow)

Suppose A sends 1 BTC to B  

1) Transaction goes to mempool (with fee)  
2) It waits there  
3) Miner selects the transaction  
4) Adds it to a block  
5) Block is added to the blockchain  

## 🔹 Fees

Based on speed:

- Slow  
- Normal  
- Fast  

➡️ Example:  
1 BTC → 1.00015 BTC (including fee)

---

## 🔹 Mining

- Requires solving computational puzzles  
- Takes time and energy  

➡️ Solo mining is difficult  

## 🔹 Mining Pool

- Multiple miners work together  
- Solve the same problem  
- Reward is distributed

## 🔹 Altcoin Features

1) Peer-to-peer digital currency

# 🪙 Tokens

A token is a digital asset created on an existing blockchain that represents value, rights, or access and follows rules written in a smart contract.

These tokens follow the technology of the same blockchain.  
Their rules, regulations, and working process are written inside a smart contract.

---

## 🔹 Smart Contract

It is like a rule book in which code is written.

When some certain criteria is triggered in the blockchain, then the written code automatically gets executed and whatever action is written in the code gets performed.

---

## 🔹 Examples

- Bitcoin → Blockchain technology, Currency: Bitcoin (BTC)  
- Ethereum → Blockchain technology, Currency: Ether (ETH)  

---

## 🔹 Transaction Fee

When transactions are performed on the network, transaction fees are charged and given to miners.

When 1 ETH is sent to someone on the network, a fee is also charged, and this is called Gas Fee.

### Why?

➡️ This is like fuel/gas to move the network.
