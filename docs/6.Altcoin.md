# 🪙 Altcoin & Tokens in Blockchain

---

## 🔹 Cryptocurrency

Crypto-currency is a type of Digital Currency in which transactions are verified and a decentralized system maintains all the transactions, such currency is called cryptocurrency.

---

## 🔹 Forking

When a new update comes in a blockchain series and all blocks accept it, but some blocks do not accept it, then a fork (separate chain) is created.

---

## 🔹 Fork Type

Soft Fork: Those which accept the updates.

Hard Fork: Those which do not accept the updates, if these blocks survive for a long time then a new coin is created, such coins are called Altcoins.

---

## 🔹 Temporary Fork

This is a type of fork which is created in the network for a temporary time.

How?

This technology is decentralized, many miners in the world are solving the same difficulty problem, so it is possible that Miner A and Miner B both at the same time, with just a few milliseconds difference, broadcast their solution to the network, then in the network both solutions are seen by different miners at different times, so some miners start working on A and some miners start working on B, so here a temporary fork is created, but later it automatically gets solved and comes back to 1 single chain.
