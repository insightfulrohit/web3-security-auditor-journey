## 🔹 Full Node

If a node has the complete copy of the entire blockchain,  
then that node is called a **Full Node**.

### Capabilities of Full Node

1) Can initiate transactions  
2) Can broadcast transactions  
3) Can verify and validate transactions  

➡️ A full node requires high system memory/storage  

---

## 🔹 Partial Node

It contains partial data and depends on other nodes for remaining information  

➡️ It mainly stores **block headers**  

➡️ It cannot perform all tasks like a full node  

---

## 🔹 Main Components of Blockchain

1) Node  
2) Ledger  
3) Wallet  
4) Nonce  
5) Hash  

---

## 🔹 Properties of Ledger

### 1) The property of being distributed  
(All nodes have a copy of the ledger)

### 2) The property of being public  
(Any node can read the ledger data)

### 3) The property of being immutable  
(Once data is recorded in the ledger, it cannot be changed)

---

## 🔹 Wallet

A wallet is a storage system where digital currency is stored  

Each wallet contains:  
- Public Key  
- Private Key  

### Example

If I want to receive Bitcoin from someone,  
I will share my **Public Key**  

Example: Like sharing your Gmail address  

---

## 🔹 Types of Wallet

### 🔸 Hot Wallet
- Online wallet  
- Used for day-to-day transactions  
- Higher security risk  

### 🔸 Cold Wallet
- Offline wallet  
- Lower security risk  
- Usually needs to be purchased

# 🔗 Types of Blockchain

---

## 🔹 1) Public Blockchain

### Features
- Most commonly used  
- Any node can join and perform transactions  
- Also known as **permissionless blockchain**

### Examples
- Ethereum  
- Bitcoin  

### Advantages
- Transparency (everyone has access to data)

### Disadvantages
- Slow transaction speed  
- Scalability issues  
- Every node verifies → more time required  

### Working
Transaction initiation → Verification → Consensus → Block formation → Ledger update  

---

## 🔹 2) Private Blockchain

### Features
- Works in a restricted environment  
- Controlled by a centralized organization  
- Only selected participants can join, read, or write data  

### Examples
- Hyperledger Fabric  
- R3 Corda  
- Quorum (by JP Morgan)  

### Use Case
Enterprises (banks, supply chain companies) where data confidentiality and speed are required  

Example:
- Walmart uses it to track food products from farm to shelf  

### Advantages
- High speed & scalability  
- Privacy (only authorized members)  
- Energy efficient  
- Better governance & control  
- Easier regulatory compliance  

### Disadvantages
- Centralization risk  
- Less transparency  
- Limited trust (depends on organization)  
- Restricted participation  

---

## 🔹 3) Consortium (Federated) Blockchain

(Semi-decentralized)

### Concept
Mix of Public + Private Blockchain  

- Any node can join and initiate transactions  
- Only selected nodes validate transactions  

### Examples
- R3 Corda  
- Energy Web Foundation  
- IBM Food Trust  

### Advantages
- Collaborative control  
- No single entity controls network  
- High efficiency  
- Better scalability  
- Trust among participants  
- Regulatory compliance  
- Balance between privacy & transparency  

### Disadvantages
- Complex governance  
- Coordination challenges between organizations  
- Not fully decentralized  
- Less transparency than public blockchain  
- Onboarding issues (adding/removing members affects system)
