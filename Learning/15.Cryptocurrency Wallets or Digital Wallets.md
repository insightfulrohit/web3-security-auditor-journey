# Cryptocurrency Wallets / Digital Wallets

## What is a Cryptocurrency Wallet?

A cryptocurrency wallet, also called a digital wallet, is a software or hardware tool that helps users manage their cryptocurrency on a blockchain.

A wallet does **not actually store cryptocurrency inside it**. The cryptocurrency remains recorded on the blockchain. The wallet stores and manages the **private keys** that allow the user to access and control those assets.

A wallet can be used to:

- Send cryptocurrency
- Receive cryptocurrency
- View wallet balances
- Manage blockchain addresses
- Sign transactions using the private key

### Example

If Rinki owns Bitcoin, her Bitcoin is recorded on the Bitcoin blockchain.

Her wallet contains the information and keys needed to prove that she can control that Bitcoin.

---

# Types of Cryptocurrency Wallets

Cryptocurrency wallets are mainly divided into two categories:

1. **Hot Wallet**
2. **Cold Wallet**

The main difference is whether the wallet is connected to the internet during normal use.

---

# 1. Hot Wallet

A hot wallet is a wallet that is connected to the internet or is designed for online use.

It is generally used for **short-term storage and everyday transactions**.

### Main Features

- Online and internet-connected
- Easy and quick to access
- Convenient for daily transactions
- Usually free to use
- More exposed to online attacks, phishing, malware, and other cyber threats

## Types of Hot Wallets

### A. Desktop Wallet

A desktop wallet is installed and used on a computer such as a desktop or laptop.

### Features

- Installed on a computer
- Gives the user direct control over the wallet
- Requires proper security of the computer
- Malware on the computer can create security risks

### Example

A user can install a Bitcoin or Ethereum wallet application on a laptop and use it to send and receive cryptocurrency.

---

### B. Mobile Wallet

A mobile wallet is a cryptocurrency wallet application installed on a smartphone.

### Features

- Easy to carry and use
- Convenient for everyday transactions
- Quick access to cryptocurrency
- Security depends heavily on the security of the mobile device and wallet application

### Example

A user can use a mobile wallet to scan a QR code and send cryptocurrency.

---

### C. Online / Web Wallet

An online wallet is accessed through a web browser or an online service.

### Features

- Can be accessed from different locations
- Requires an internet connection
- Very convenient
- Security depends on the wallet/service and the user's account security

---

# 2. Cold Wallet

A cold wallet is a wallet that keeps the private keys offline and is not normally connected to the internet.

It is generally used for **long-term storage**.

### Main Features

- Private keys are kept offline
- Does not normally require an internet connection
- Less exposed to online attacks
- Less convenient for frequent transactions
- Some cold wallets require purchasing a physical device

## Types of Cold Wallets

### A. Hardware Wallet

A hardware wallet is a physical device specially designed to store and protect private keys.

The private key normally remains inside the device and is used to sign transactions.

### Features

- Physical device
- Private keys are kept offline
- Designed for better protection against online attacks
- Useful for long-term storage
- The device must still be protected from physical loss, theft, and unauthorized access

### Examples

- Ledger
- Trezor

---

### B. Paper Wallet

A paper wallet is a physical piece of paper containing wallet information such as a private key and/or public address.

It is an offline form of key storage.

### Features

- Completely offline
- No internet connection is required
- Can be affected by physical damage, loss, or theft
- A private key printed on paper must be protected very carefully

**Note:** Paper wallets are an older method and are generally not recommended for most modern users because key generation, printing, and backup can introduce security risks.

---

# Hot Wallet vs Cold Wallet

| Feature | Hot Wallet | Cold Wallet |
|---|---|---|
| Main Use | Short-term storage and everyday transactions | Long-term storage |
| Internet | Usually connected to the internet | Normally offline |
| Accessibility | Very easy to access | Less convenient |
| Cost | Usually free | Hardware wallets usually cost money |
| Online Attack Risk | Higher | Lower |
| Convenience | High | Lower |
| Examples | Desktop, Mobile, Web wallets | Hardware, Paper wallets |

---

# Hot Wallet vs Cold Wallet: Simple Example

Suppose Rinki has cryptocurrency that she uses regularly for payments.

She may keep a small amount in a **hot wallet** because it is easy to access and use.

Now suppose Rinki has a large amount of cryptocurrency that she wants to hold for a long time.

She may use a **cold wallet**, such as a hardware wallet, to keep the private keys offline and reduce exposure to online attacks.

---

# Important Security Points

A cryptocurrency wallet is only as secure as the way its keys and recovery information are protected.

### 1. Protect the Private Key

Never share your private key with anyone.

Anyone who controls the private key may be able to control the cryptocurrency associated with it.

### 2. Protect the Seed Phrase

Many wallets provide a recovery phrase, also called a seed phrase.

It can be used to restore access to the wallet.

Never share the seed phrase with anyone and do not store it in an insecure online location.

### 3. Beware of Phishing

Attackers may create fake wallet websites, applications, or messages to steal private keys or seed phrases.

Always verify the wallet application and website before entering sensitive information.

### 4. Use Strong Device Security

Keep your computer and smartphone protected with:

- Strong passwords or PINs
- Screen lock
- Updated operating system
- Updated wallet software
- Trusted applications only

### 5. Check Transaction Details

Before confirming a transaction, carefully check:

- Receiver address
- Amount
- Network
- Transaction fee

Blockchain transactions are generally difficult or impossible to reverse after confirmation.

---

# Key Takeaway

A **cryptocurrency wallet does not store cryptocurrency itself**. The cryptocurrency remains on the blockchain, while the wallet manages the keys needed to access and control it.

- **Hot Wallet = Online + Easy access + Everyday use**
- **Cold Wallet = Offline + Better protection from online attacks + Long-term storage**

For larger or long-term holdings, keeping private keys offline can reduce online attack exposure. For frequent transactions, hot wallets are usually more convenient.
