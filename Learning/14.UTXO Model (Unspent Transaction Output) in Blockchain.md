# 🔹 UTXO Model (Unspent Transaction Output) in Blockchain

## 📌 What is UTXO?

UTXO (Unspent Transaction Output) is the amount of cryptocurrency that has been received in a transaction but **has not yet been spent**, and can be used as input in a future transaction.

> Simple: Wallet balance = Sum of all UTXOs

---

## 🧠 Basic Concept

- Every transaction:
  - Uses **Inputs (old UTXOs)**
  - Creates **Outputs (new UTXOs)**
- A UTXO can be **spent only once**

---

## 💡 Example 1

Assume:

- Rinki has **10 BTC (UTXO)** in her wallet

If she sends 3 BTC to someone:

### 🔄 Transaction:

- Input:
  - 10 BTC (old UTXO)

- Output:
  - 3 BTC → Receiver
  - 7 BTC → Rinki (change)

👉 Now:
- 10 BTC UTXO is **consumed**
- 3 BTC + 7 BTC are **new UTXOs**

---

## 💡 Example 2 (Based on Notes)

Rinki has: **5 BTC**

She sends:
- 3 BTC → Rohit

### 🔄 Output:

- 3 BTC → Rohit
- 2 BTC → Rinki (change / return)

👉 Important:
- This 2 BTC is **automatically returned as change**
- A **new address is generated** for this change (for privacy)

---

## 🔐 Why Change Address?

- Improves privacy
- Makes tracking difficult
- Encourages use of a new address per transaction

---

## ⚙️ UTXO Working Flow

1. User initiates a transaction
2. Wallet selects available UTXOs
3. Inputs = Selected UTXOs
4. Outputs are created:
   - Receiver
   - Change (back to sender)
5. Old UTXOs → spent
6. New UTXOs → stored on blockchain

---

## ❗ Important Rules

- UTXO **cannot be partially spent**
- Entire UTXO is consumed
- Extra amount → returned as change

---

## 🔁 Relation with Double Spending

- A UTXO can be used **only once**
- If someone tries to reuse the same UTXO:
  - ❌ Transaction is rejected
- This mechanism **prevents double spending**

---

## 🚀 Improvements / Advanced Points

### ✅ 1. UTXO Selection Strategy
- Wallet may combine smaller UTXOs
- Helps optimize transaction fees

### ✅ 2. Transaction Fees
- Input > Output
- Difference = Miner fee

### ✅ 3. Parallel Transactions
- Different UTXOs can be used simultaneously
- Improves scalability

### ✅ 4. Security Advantage
- Each transaction is independent
- Reduces attack surface

---

## 🔍 UTXO vs Account Model (Quick Comparison)

| Feature        | UTXO Model         | Account Model |
|---------------|------------------|--------------|
| Balance       | Multiple outputs | Single balance |
| Privacy       | High             | Lower |
| Complexity    | Higher           | Simpler |
| Used in       | Bitcoin          | Ethereum |

---

## 🧾 Summary

- UTXO = Unspent balance chunks
- Each transaction → consumes old and creates new outputs
- Change output is a key concept
- Prevents double spending
- Core model used in Bitcoin

---

## 🎯 Final Line

> "In blockchain, value is not stored as a single balance, but as **multiple UTXO chunks**."
